# 坦克大战 · Tank Battle

一个用纯 HTML / CSS / JavaScript（Canvas）实现的经典《坦克大战 / Battle City》网页小游戏。**零依赖、单文件**，直接用浏览器打开即可游玩。

## 运行方式

- 直接用浏览器打开 `index.html`，或
- 本地起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击 |
| P | 暂停 |
| M | 静音 |
| Enter | 开始 / 重新开始 |

## 玩法

- 守卫基地（🦅），消灭全部敌军坦克即可过关
- 砖墙可被炮弹摧毁，钢铁墙需要强化炮弹，水域会阻挡坦克
- 击毁**闪烁的**敌军坦克会掉落道具：
  - ★ 强化炮弹（可击穿钢铁）
  - ⛨ 护盾（短暂无敌）
  - ♥ 增加生命
  - ✸ 全屏清敌
  - ❄ 冻结敌军
- 每过一关，敌人会更多、更快

## 技术

- 单文件 `index.html`，Canvas 渲染，像素风
- 固定 60fps 步长的游戏循环
- Web Audio 合成音效
- 支持触屏（手机上会自动显示虚拟摇杆）
